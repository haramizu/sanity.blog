# Sanity ブログ

[Readme English](README.md)

このリポジトリでは、Wordpress から移行してきたブログサイトを前提として、ブログサイトを立ち上げるためのサンプルコードを展開しています。

Wordpress からの移行の手順は以下のページで公開しています。

- [Migrating content from WordPress to Sanity](https://www.sanity.io/learn/course/) 公式
- [Wordpress から Sanity への移行](https://www.haramizu.com/ja/docs/sanity/migration-from-wordpress-to-sanity/) 私のブログ

## Sanity 

このリポジトリで展開しているサンプルでは Sanity をブログの CMS として採用しています。Sanity はコンテンツ管理の仕組みでヘッドレス CMS のアーキテクチャを採用している Content Operation System です。詳細な情報は以下の公式サイトから確認することができます。

- [The Content Operating System | Sanity](https://www.sanity.io)

ブログサイトで Sanity に関して取り上げています。

- [Sanity](https://www.haramizu.com/ja/docs/sanity/) - haramizu.com

このリポジトリのサンプルを利用するためには、Sanity のアカウントが必須となります。
