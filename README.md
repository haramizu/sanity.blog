# Sanity Blog

[Readme 日本語](README_ja.md)

This repository provides sample code for setting up a blog site, assuming you're migrating from WordPress.

The migration procedure from WordPress is published on the following page.

- [Migrating content from WordPress to Sanity](https://www.sanity.io/learn/course/) Official
- [Migration from Wordpress to Sanity](https://www.haramizu.com/en/docs/sanity/migration-from-wordpress-to-sanity/) My Blog

## Sanity 

The sample deployed in this repository uses Sanity as its blog CMS. Sanity is a Content Operation System that employs a headless CMS architecture for content management. Detailed information can be found on the official website below.

- [The Content Operating System | Sanity](https://www.sanity.io)

We are covering Sanity on our blog site.

- [Sanity](https://www.haramizu.com/ja/docs/sanity/) - haramizu.com

To use the samples in this repository, a Sanity account is required.
